Yardım Merkezi

Teknoify’nin doğrulanmış uygulama akışları için hızlı yanıtları bulun.

Dokümantasyon

Profil bilgilerimi nasıl güncellerim?

Profil ve Güvenlik sayfasındaki “Profili Düzenle” düğmesi, mevcut ortak profil yöneticisini açar. Desteklenen profil alanları buradan kaydedilir.

API anahtarını nereden oluşturabilirim?

Genel API anahtarı oluşturma altyapısı şu anda bulunmuyor. API Yönetimi sayfası mevcut BİM istek konsoluna, ayrı erişim sınırlarını belirterek yönlendirir.

Takım üyesi davet edebilir miyim?

Kuruluş üyelik ve davet modeli desteklenmediği için davet gönderme işlemi sunulmuyor.

Faturalarımı nereden indirebilirim?

Yetkili platform fatura kaynağı ve indirme uç noktası bağlı değildir. Faturalar sayfası bu eksikliği boş hesap geçmişi gibi göstermeden açıklar.

Menüyü mobil cihazda nasıl kullanırım?

Üst çubuktaki menü düğmesi uygulama çekmecesini açar. Escape tuşu veya arka plan alanı menüyü kapatır.
