# 18 — Canonical Tools page system: the five Araçlar pages on the AI Agent standard

Date: 2026-09-08. Branch: `feat/canonical-tools-page-system` (from `main` at `2121a10`).

The six canonical Araçlar pages (AI Agent, Web Scraping, API & Entegrasyon, Robotik Süreç Otomasyonu, Finansal İndikatör & Botlar, Eğitim & Danışmanlık) now share one visual and technical system. The AI Agent page (doc 17) was the design source; its grammar was extracted into shared files and the five legacy service pages were recomposed on it from their own factual content. Legacy routes (`ai-assistant`, `investment-analytics`, `subscription`, the legal pages) are untouched apart from the shared header and footer stamping they already had.

## 1. Architecture

| Layer | File | Role |
|---|---|---|
| Shared grammar | `css/tools/tools-page.css` | Root `main.tools-page` with the purple tokens; type (`tp-kicker`, `tp-h2`, `tp-lead`, `tp-note`); `tp-section`; split layouts (`tp-split`, `--tight`, `--wide`, `--center`, `__sticky`); hero (`tp-hero`); process rail (`tp-rail`); linked cells (`tp-cells`, `--3`); definition rows (`tp-def`); numbered list (`tp-list`); panels and tags (`tp-panels`, `tp-panel`, `tp-tags`); chips (`tp-chips`, `--pending`); stepped vignette (`tp-run`); transcript (`tp-log`); data surface (`tp-data`); final CTA overrides; the phone rhythm block; reduced motion. Unlayered, loaded after `css/style.css`, before `css/01-foundation/shell-responsive.css`. |
| Page visuals | `css/tools/{ai-agent,webscraping,api,rpa,fi}.css` | Only the page's signature visualisation (44–60 lines each). Training needs none. |
| Shared behaviour | `js/experience/tools.js` | `mountToolsPage()` (hero entrance, reveals via `closing.js`, per-section field ownership on the shared scheduler), `oncePlayer()` (once-per-visit lifecycle: first view plays, leaving early or hiding the tab resolves to the final state, no replay, reduced motion shows the end), `stageSteps()`, `playRunVignette()` (generic `tp-run` sequencing). |
| Page modules | `js/experience/tools/{ai-agent,webscraping,training}.js` (3 lines each, generic run) and `{api,rpa,fi}.js` (custom sequences). | One IntersectionObserver-driven timer sequence per page; no page loop. The field is mounted through `shell.js`: one canvas, one scheduler. |
| Header and footer | `scripts/shell/header.template.html`, `scripts/shell/footer.template.html`, `scripts/shell/sync-shell.mjs` | The footer template (the homepage footer with destination placeholders) is stamped into pages carrying `<!-- shell:footer -->` markers: the six Tools pages. Removed: `css/ai-agent.css` and `js/experience/agent.js` (replaced by the files above); `css/api.css`, `css/rpa.css`, `css/webscraping.css`, `css/financial-indicators.css`, `css/training-consulting.css` (each was used only by its own page; proven by grep before deletion). `css/ai-assistant.css` and the legacy component CSS in `css/style.css` stay because the noncanonical pages use them.

## 2. AI Agent as the regression source

The refactor renames the AI Agent page's classes to the shared `tp-*` names with identical values. Geometry diff against production (every section, heading, paragraph, list, panel, footer element at 1440 and 390): no differing box. Full-page pixel diff shows only one intentional correction: the old page's transcript accidentally inherited the homepage journey's `.log li` rule (a 1px extra bottom border on each row and an 8px leftward shift of the tool chips); the rename removed that leak, so chips now align with the text column and separators are single hairlines. Page height 5,289 → 5,284 px at 1440. The vignette lifecycle (once per visit) re-verified.

## 3. The five pages

Each page: hero (kicker, editorial H1 with one lavender phrase, lead, primary and secondary CTA, signature visual in the window surface) → chapters in an order chosen for the product → the canonical final CTA → the canonical footer. Copy is the legacy page's factual content, reorganised and tightened; nothing new was claimed.

- **Web Scraping** (`hero → nasıl çalışır (rail) → neler toplanabilir (6 cells) → çıktı (definition rows + dataset preview) → kontrol (list) → CTA`). Visual: extraction vignette — source URL typed, structures discovered, fields as chips, rows of a dataset filling in, "Veri seti hazır · CSV · JSON · API". Copy changes: "milyonlarca sayfa", "haftalar → dakikalar", "günlük milyonlarca satır" and the data-point counter dropped; "LinkedIn & İş İlanları", "Google Maps Lokasyonları" and "Sosyal Medya Yorumları" generalised to "İş ilanları", "Lokasyon verileri", "Yorum ve değerlendirmeler"; planned re-collection stated as on the homepage (planlı tarama, değişiklik izleme). Field: hero → calm → lanes → order → calm → pulse.
- **API & Entegrasyon** (`hero → rail → örnek akış (transcript + definition rows) → entegrasyon alanları (6 cells) → neden (list) → CTA`). Visual: routing vignette — source systems, the Teknoify integration layer, destinations; a packet travels the route once; states "Bağlantı hazır", "Veri eşitlendi", "Akış çalışıyor". Copy changes: the "%100 veri tutarlılığı" counter dropped in favour of "tutarlı veri"; "gerçek zamanlı" softened to "olay bazlı veya planlı eşitleme"; OAuth2/JWT/SSL kept as stated; pazaryeri names (Trendyol, Hepsiburada) kept because the legacy page states them; "webhook" not introduced. Primary CTA is contact (a service), secondary the platform.
- **Robotik Süreç Otomasyonu** (`hero → neleri otomatikleştirebilirsiniz (6 cells) → rail → bir akış (transcript + definition rows) → neden (list) → CTA`). Visual: workflow vignette — four steps (Veri al, Kontrol et, İşle, Sonucu aktar) executing with a run record. Copy changes: "%80 hız", "hata oranı = 0", "7/24", "yatırım maliyetini kısa sürede geri" removed; replaced by "daha az hata", "mesaiden bağımsız", "odak"; no robot imagery.
- **Finansal İndikatör & Botlar** (`hero → rail → kural tabanlı çalışma (transcript + definition rows) → neden (list + note) → çözümler (6 cells) → CTA`). Visual: monitoring vignette — a representative indicator line and moving average, a threshold rule, a four-stage pipeline resolving into "Bildirim hazır"; no symbols, prices or numbers. Copy changes: "%X başarı oranı", "kâr potansiyeli", "AL SİNYALİ", crypto tickers and "duygusal kararları ortadan kaldırın" removed; the page frames everything as user-defined rules and adds the note "Teknoify yatırım tavsiyesi vermez…"; TradingView, Binance, Telegram kept because the legacy page states them.
- **Eğitim & Danışmanlık** (`hero → nasıl ilerliyoruz (rail) → programlar (6 cells) → yaklaşım (two panels) → neden (list) → CTA`). Visual: roadmap vignette on the shared stepped run (İhtiyaç, Yol haritası with module chips, Eğitim, Uygulama). Copy changes: the hours counter and "binlerce saat" dropped; "%100 uygulamalı" kept as "uygulamalı"; quieter, editorial composition (panels instead of a transcript).

Metadata normalised on all five: `<title>` uses the canonical product name (`API & Entegrasyon | Teknoify` replaces `API Entegrasyon Hizmetleri`), a description per page, and `<link rel="canonical">` in the extensionless form the sitemap already publishes and production serves (`pretty_urls = true`, verified 200 on the extensionless routes). Font Awesome stays loaded for the shared header only; no page content uses icons.
